# Printable parts

Every part of the arm that comes off a printer, split into the order you need it. Start with folder 01 and work down - you can begin assembling the base while the rest is still printing.

- `01_base_and_j1` - Base and J1 turret, 23 parts
- `02_j2_shoulder` - J2 shoulder, 8 parts
- `03_j3_elbow` - J3 elbow and upper arm, 20 parts
- `04_j4_forearm` - J4 forearm roll, 14 parts
- `05_j5_j6_wrist` - J5 and J6 differential wrist, 25 parts
- `06_gripper` - Gripper, 9 parts
- `07_forearm_lids` - Forearm lids, 2 parts

Each folder has an STL and a STEP for every part. Print the STL; the STEP is there if you would rather re-mesh it yourself or change something.

The assembly guide is not published yet. Until it is, the folder order is the build order.
